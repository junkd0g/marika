Marika privacy policy

Marika is a Mac workspace for development and testing. Your projects, chat history, drafts, tickets, QA evidence and browser state are stored on your Mac. Marika does not operate a service that receives your chat history.

Agent and browser sharing

When you send a message or start an agent task, the provider you choose receives the prompt, selected attachments and project information used in the task. Codex uses OpenAI and Claude uses Anthropic. Your provider account, settings and its retention policy govern data the provider receives. Design Import sends the selected snippets for analysis.

Browser tool sharing starts off. If you enable Agent access, agents can read URLs, page text and screenshots and interact with signed-in pages in all tabs of that project. Turn it off in the Browser toolbar to revoke future access. You can also explicitly add a screenshot to a chat draft. Sending the draft shares it with the selected provider.

Testing and connections

Recording a QA journey captures actions and ordinary input in the selected tab. Stop recording from QA. Screenshots and bug evidence may contain information visible on the page. Review evidence before sharing it. Browser navigation, API requests, Git remotes, monitoring services, tools and authentication contact the destinations you configure or visit. Those services receive the information needed for the request.

Storage and deletion

Marika keeps workspace files, evidence, attachments and recovery backups locally until you remove them. Deleting a conversation removes its transcript; saved attachments and backups can remain in Saved Data. Use the app’s Saved Data folder to locate these files. Quit Marika before deleting its saved workspace. Use Browser settings to clear website data and connection settings to disconnect accounts. To remove data already shared with a provider, use its account controls.
