# Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/junkd0g/marika/security/advisories/new)
for issues involving credential exposure, permission bypasses, unexpected command execution
or data loss. Include reproduction steps and the affected version. Remove tokens, private
repository content and personal information from attachments.

For ordinary bugs, use the issue tracker. Do not post security-sensitive details in public issues.

Marika is early software. The latest `main` branch is the currently maintained version.
Agent permissions are enforced by the selected agent runtime; see
[approval modes](docs/approval-modes.md) for their behavior and limits.
